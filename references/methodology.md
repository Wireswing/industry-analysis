# 分析方法体系（修正版）

> 本文档是产业分析报告的方法口径唯一来源。所有公式相对"通用产业智能分析平台 v6"做了修正，每处修正以 **[修正]** 标注原因。报告 HTML 的"方法说明"页展示的是本文的精简版（自动由模板渲染，含局限声明）。

## 0. 统一数据 schema 与预处理

### 企业记录（统一 schema）

```json
{
  "name": "沈阳XX航空科技有限公司",
  "lat": 41.7952, "lng": 123.4567,
  "coord_sys": "gcj02",
  "capital": 5000,            // 注册资本（万元）
  "est_date": "2019-04-12",   // 成立日期（优先）；缺省可用 age（年）替代
  "age": 6.5,                 // 由 est_date 计算，或数据自带
  "scale": "中型",             // 大型/中型/小型/微型/未知
  "scope": "航空发动机零部件制造、维修",  // 经营范围
  "gbt_code": "3742",         // GB/T 4754-2017 行业代码（2-4位）
  "status": "在业"            // 在业/注销/吊销/迁出（可选）
}
```

预处理规则：
- **[修正]** 年龄统一由 `est_date` 计算（`age = (分析基准日 - 成立日期)/365.25`）；`age` 或 `est_date` 均缺失的记录**剔除出活力/象限计算**并计入 `missing.age_rate`（缺失率 > 20% 时在报告中黄字提示），不再把缺失值默认当新设企业。
- **[修正]** `status` 非在业（注销/吊销）的企业默认从地图与各模块剔除，但计入**存活率**指标（在业数/总数），作为活力的负向信号。
- 坐标系默认 GCJ-02（与高德底图、DataV 边界一致）；`wgs84`/`bd09` 由模板前端自动转换（GCJ↔WGS 约 ±500m、BD↔GCJ 约 ±100m）。

### 空间距离（所有空间计算的前提）

**[修正]** v6 直接用经纬度"度"计算欧氏距离，在 41.8°N 纬度下东西向距离被高估约 25%，DBSCAN 聚类形状与 Moran's I、网格都会畸变。统一改为**等距圆柱投影**后再以米计算：

```
φ0 = 研究区平均纬度
x = lng × 111320 × cos(φ0)     （米）
y = lat × 110574                （米）
```

DBSCAN 的 `eps` 因此以**米**给出（默认 800m，对应 v6 的 0.012° 意图），网格尺寸同样按米→度换算。

## 1. 空间聚类（DBSCAN）与集群画像

- 算法：标准 DBSCAN，投影坐标（米）下 O(n) 网格加速实现；`eps`（米，默认 800）、`minPts`（默认 5）。
- **[修正] 集群编号**：DBSCAN 原始 cid 与规模无关，且 v4 给每个企业点叠编号导致重叠。统一按**企业数降序重排为 C1、C2…Cn**，地图上仅在**集群质心**放置一个编号标签（样式参考 v4：黑底白字圆形徽章 + 集群色描边 + 企业数），表格、象限图、地图三处编号一致。
- **[修正] 集群命名**：质心落点与行政边界（DataV 区县面）做 point-in-polygon 匹配，自动命名为 `"{区县名}·{主导产业}集群"`，无法匹配时退回 `集群C{i}`。
- 集群画像指标：
  - 企业数 n、平均/总注册资本、大中型占比、近 3 年新设占比（**存活企业口径**）
  - **当前实力** `strength = 0.40×规模分 + 0.35×资本强度 + 0.25×大中型占比`（各分量归一化 [0,1]）
  - **发展潜力** `potential = 0.50×新设占比 + 0.30×新设企业资本强度 + 0.20×密度`
  - **[修正]** 密度项原为 `min(1, n/10)`（≥10 家即满分，0.2 权重失效），改为 `min(1, n/面积)` 的对数尺度：`密度分 = log(1+n)/log(1+n_max)`。
  - 象限切割：**[修正]** 集群数 ≥4 用中位数切割（保持 v6 口径）；<4 改用均值切割并在报告标注"集群数少，象限结论稳健性有限"。
- 象限建议（沿用）：★明星→深化专业化/标杆园区；◆成熟→巩固升级/引入研发；▲潜力→基建与龙头引育；▽弱势→重新定位/选择性整合。

### Moran's I（辅助检验）

**[修正]** v6 实现：取前 500 家（非随机抽样）、无显著性检验、用注册资本做属性却宣称"集聚显著"。修正为：
- 全样本（或网格聚合后）计算，空间权重用 **k 近邻（k=8）行标准化**；
- 报告 Moran's I（基于 log 资本）与**置换检验 p 值**（199 次重排）；
- 明确表述为"注册资本的空间自相关"，企业集聚本身由"集群内企业占比"刻画。

## 2. 产业活力指数

```
活力 = w1×新设率 + w2×资本强度 + w3×集群密度      （w1+w2+w3=100%，默认 40/35/25）
新设率   = 近3年成立（在业）/ 类别内在业企业数
资本强度 = 归一化( log(1+平均注册资本) )           [0,1]
集群密度 = 类别内落在 DBSCAN 集群的企业占比（未跑聚类模块时该维度记 0.5 并提示）
存活率   = 在业 / (在业+注销+吊销)（有 status 字段时输出，作为附加负向信号）
```

**[修正]** 资本强度原为 min-max 归一化，受单一巨头极值压扁（注册资本重尾分布），改用 log 变换后 min-max。
生命周期：年龄分箱 0-3 / 3-8 / 8-15 / 15+ 年（口径不变）。

## 3. LQ 区位商（专门化）

```
LQ_i = (本地产业 i 企业数/本地总企业数) / (基准区产业 i 企业数/基准区总企业数)
LQ > 1.25 显著优势（重点培育）| 0.75~1.25 均衡 | < 0.75 相对薄弱（考虑招引）
```

**[修正]** v6 在基准缺失时用"均匀分布 1/类别数"兜底并照常输出结论——不可解释。修正分三档：
1. 用户提供基准（推荐：全省/全国产业结构，企业数或占比口径需注明）→ 正常输出；
2. 使用内置参考基准（本文件附录 B）→ 输出并标注"内置参考基准"；
3. 无任何基准 → **降级**：仅输出"本地产业结构占比"，LQ 列显示"—"，并提示补充基准后可计算。
置信提示：任一类别企业数 < 30 时，LQ 标注 `n<30`，报告中说明小样本波动风险。

## 4. 选址网格适宜性

```
综合得分 = 0.30×交通可达 + 0.30×人才供给 + 0.25×产业集聚 + 0.15×商业配套
交通可达 = min(1, 网格2km内地铁站POI数/2)
人才供给 = min(1, 网格3km内高校POI数/3)
产业集聚 = min(1, 网格内企业数/20)
商业配套 = min(1, 网格2km内商圈+医院POI数/2)
```

**[修正]** 三处：① v6 的"用地条件"维度恒为 0.5（权重 15% 不改变任何排序，纯无效权重），默认移除并将权重重标为 30/30/25/15；若用户能提供用地数据（GeoJSON/表格）可恢复该维度（预留注入位）。② v6 的 `gridTarget`（高技术/制造/服务）选择器未接入任何计算（虚假功能），移除；如需分目标权重，在 analyze.py 参数中显式配置。③ 网格与企业匹配由 O(网格×企业) 改为分桶一遍扫描；无 POI 数据时，交通/人才/配套维度自动置 0 并提示"仅产业集聚维度有效"。
评级：>0.6 优先选址 / 0.35~0.6 适宜 / <0.35 一般（口径不变）。

## 5. 产业链诊断

将企业匹配到目标产业的链条环节，计算覆盖度并识别短板/优势。

- 匹配：**GBT 代码映射优先**（环节→GBT 编码表，见产业库），经营范围关键词命中作为补充；关键词命中率**归一化**（命中数/该环节词库数）**[修正：v6 按绝对命中数打分，词库大的环节天然占优]**。
- 环节得分（0-1）：
  ```
  环节得分 = 0.45×数量分 + 0.35×资本分 + 0.20×龙头分
  数量分 = log(1+企业数)/log(1+max企业数)
  资本分 = 环节注册资本/最大环节注册资本
  龙头分 = 有大中型企业 ? 1 : 0
  ```
  **[修正]** v6 的"存在性(0.30)"与数量分强相关，构成双重计分，已并入数量分。
- 短板 = 企业数 0 的环节（招引重点）；优势 = 得分 > 0.4 的环节。
- 局限声明（报告固定展示）：匹配基于经营范围关键词与国标代码，为启发式方法，个体企业可能跨环节或漏配；结论应结合龙头企业访谈校验。

## 6. 产业韧性（集中度与结构）

**[修正]** v6 仅用企业数份额计算 HHI，并直接套用源自市场份额口径的 0.10/0.18 阈值——语义错位（企业数量集中 ≠ 产出集中）。修正为**双口径 + 参照系**：

```
HHI_count   = Σ(企业数份额²)      按企业数
HHI_capital = Σ(资本份额²)        按注册资本
CR4         = 前4家注册资本合计 / 全部注册资本     （新增，龙头集中度）
参照：k 个类别完全均匀时 HHI = 1/k。报告同时给出 1/类别数 作为"均匀参照线"，
      不再单独给出 0.10/0.18 的绝对风险评级，而是以参照线的倍数解读
      （如 HHI_capital > 3×均匀参照 → 结构显著集中）。
```
规模结构：大型/中型/小型/微型占比 + 缺失率（口径不变，补充缺失口径披露）。

## 7. 报告固定局限声明（模板自动展示）

1. 工商注册口径数据反映"注册分布"而非"实际经营分布"（注册地 ≠ 厂址）。
2. 关键词/GBT 启发式分类存在误差，跨产业经营的企业按最优得分归入单一产业。
3. LQ 与基准口径（企业数 vs 产值/就业）不同，仅反映相对结构。
4. 小样本（类别 < 30 家、集群 < 4 个）结论稳健性有限，均已就地标注。
